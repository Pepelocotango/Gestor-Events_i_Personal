# Lloc web de Gestor d'Esdeveniments i Personal

Aquest és el codi font de la pàgina web de Gestor d'Esdeveniments i Personal, desenvolupada amb Astro i desplegada a Vercel.

## 🚀 Començem

1. **Instal·la les dependències**
   ```bash
   pnpm install
   ```

2. **Inicia el servidor de desenvolupament**
   ```bash
   pnpm run dev
   ```
   Obrir [http://localhost:4321](http://localhost:4321) al navegador.

3. **Compila per a producció**
   ```bash
   pnpm run build
   ```
   Això generarà els arxius estàtics a la carpeta `dist/`.

## 🛠 Eines utilitzades

- [Astro](https://astro.build/) - El framework web per a llocs ràpids
- [Tailwind CSS](https://tailwindcss.com/) - Un framework CSS d'utilitats
- [Vercel](https://vercel.com) - Allotjament i desplegament

## 📁 Estructura del projecte

```
/
├── public/             # Arxius estàtics (imatges, fonts, etc.)
├── src/
│   ├── components/     # Components d'Astro/React
│   ├── layouts/        # Plantilles de pàgina
│   └── pages/          # Pàgines del lloc web
```

## 🌐 Desplegament

El lloc es desplega automàticament a Vercel quan es fa push a la branca `main`.

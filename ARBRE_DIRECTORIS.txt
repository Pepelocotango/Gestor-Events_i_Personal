## Fitxers i Carpetes Exclosos (via .gitignore)

A continuació es detallen els elements que no formen part del control de versions i la seva justificació.

### Dependències
- `node_modules/`
  - **Descripció:** Conté totes les dependències de Node.js.
  - **Motiu:** Es regenera automàticament executant `npm install`.

### Fitxers de Compilació
- `dist/`
  - **Descripció:** Carpeta de sortida dels fitxers compilats i empaquetats.
  - **Motiu:** Són artefactes generats automàticament pel procés de compilació (`npm run build`).

### Variables d'Entorn i Secrets
- `.env`, `.env.local`, `.env.*.local`
  - **Descripció:** Fitxers que contenen variables d'entorn locals com claus d'API.
  - **Motiu:** Contenen informació sensible que no ha de ser compartida al repositori.
- `google-credentials.json`, `service-account.json`
  - **Descripció:** Fitxers de credencials per a l'autenticació amb les API de Google.
  - **Motiu:** Contenen secrets d'autenticació i són altament sensibles.

### Fitxers Auto-generats
- `packages/desktop/src/index.css`
  - **Descripció:** El fitxer CSS final utilitzat per l'aplicació.
  - **Motiu:** Es genera automàticament a partir de `index.css.template` amb `npm run build:theme`.
- `packages/core/src/utils/themeDefinition.ts`
  - **Descripció:** Fitxer TypeScript amb les definicions de tipus per al tema de colors.
  - **Motiu:** Es genera automàticament a partir de `theme.config.cjs` amb `npm run build:theme`.

### Logs i Configuració Local
- `logs/`, `*.log`, `npm-debug.log*`, etc.
  - **Descripció:** Fitxers de registre (logs).
  - **Motiu:** Són fitxers temporals específics de cada execució.
- `.vscode/`, `*.code-workspace`, `.idea/`
  - **Descripció:** Configuracions específiques de l'IDE.
  - **Motiu:** Són preferències personals de cada desenvolupador.
- `.DS_Store`, `Thumbs.db`
  - **Descripció:** Fitxers de metadates generats automàticament per macOS i Windows.
  - **Motiu:** No tenen relació amb el projecte.
- `__pycache__/`, `*.pyc`
  - **Descripció:** Cache de bytecode generada per Python.
  - **Motiu:** Artefactes de compilació de scripts d'ajuda.
